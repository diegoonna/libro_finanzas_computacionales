Apéndice B — Obtención de Datos Financieros

A lo largo del libro trabajamos con datos simulados: son reproducibles, no dependen de internet y dejan el foco en los conceptos. Pero varios ejercicios te invitan a “descargar datos reales” — y en el trabajo profesional, conseguir datos limpios es la mitad del oficio. Este apéndice presenta las tres fuentes que cubren el 95% de las necesidades: yfinance (precios de mercado, gratis), FRED (macro, gratis) y Bloomberg (el estándar institucional, pago).

AdvertenciaLos bloques de este apéndice no se ejecutan en el libro

A diferencia del resto del libro, el código de este apéndice está marcado como no ejecutable (eval: false): requiere conexión a internet, claves de API o —en el caso de Bloomberg— una terminal con licencia. Las salidas que se muestran son ejemplos ilustrativos. Copiá el código a tu entorno para correrlo de verdad.

B.1 El patrón profesional: descargar una vez, trabajar en local

Antes de las herramientas, el hábito. El error típico del principiante es poner la descarga adentro del análisis: cada corrida vuelve a pedir los datos a la API — lento, frágil (la API puede fallar o cambiar) e irreproducible (los datos de hoy no son los de ayer si el proveedor corrige algo). El patrón correcto separa las dos etapas:

  1. Script de descarga: pide los datos y los guarda en disco (CSV o Parquet).
  2. Análisis: lee siempre del archivo local (pd.read_csv, como en el Capítulo 6).
# --- 1) descargar_datos.py: se corre UNA vez (o cuando querés actualizar) ---
import yfinance as yf

datos = yf.download("AAPL", start="2020-01-01", end="2024-12-31", auto_adjust=True)
datos.to_csv("datos/aapl.csv")

# --- 2) analisis.py: lee del disco, reproducible siempre ---
import pandas as pd
precios = pd.read_csv("datos/aapl.csv", index_col="Date", parse_dates=True)

Beneficios: tus resultados son reproducibles (el archivo no cambia), el análisis corre sin internet, y no castigás a la API gratuita con cien pedidos idénticos por día.

B.2 yfinance: precios de mercado, gratis

yfinance descarga datos de Yahoo Finance: acciones, ETFs, índices, monedas y cripto de casi cualquier mercado del mundo. Se instala con pip install yfinance.

import yfinance as yf

# Un ticker: precios diarios ajustados
aapl = yf.download("AAPL", start="2023-01-01", end="2024-01-01", auto_adjust=True)
print(aapl.head(3))
#                   Open        High         Low       Close    Volume
# Date
# 2023-01-03  128.782447  129.395300  122.762418  123.632286  112117500
# 2023-01-04  125.283842  126.845998  123.809612  124.907707   89113600
# 2023-01-05  125.876932  126.263764  123.276929  123.583961   80962700

# Varios tickers a la vez: devuelve columnas jerárquicas (un nivel por ticker)
panel = yf.download(["AAPL", "MSFT", "SPY"], start="2023-01-01", auto_adjust=True)
retornos = panel["Close"].pct_change().dropna()

# Dividendos y splits de un activo
ticker = yf.Ticker("AAPL")
print(ticker.dividends.tail(3))
print(ticker.splits)

Tres puntos que importan:

  • auto_adjust=True te da precios ajustados por dividendos y splits — el retorno total que el Capítulo 8 mostró que es el correcto para estimar \(\mu\). Sin ajustar, subestimás sistemáticamente el retorno de los activos de alto dividendo.
  • El parámetro interval permite otras frecuencias: "1wk", "1mo", e intradiario ("1h", "5m") con historia limitada.
  • Para tickers argentinos en BYMA se usa el sufijo .BA: "GGAL.BA", "YPFD.BA" (pesos); los ADRs ("GGAL", "YPF") cotizan en dólares de NY — no los mezcles sin pensar en qué moneda estás.
AdvertenciaLas limitaciones de lo gratuito

yfinance usa una API no oficial de Yahoo: puede romperse tras cambios del sitio (actualizá la librería si deja de funcionar), tiene rate limits (descargas masivas → bloqueos temporales), y la calidad es de “análisis personal”, no de auditoría: hay huecos y correcciones ocasionales. Además, ojo con el sesgo de supervivencia (Capítulo 17): si armás tu universo con los tickers de hoy, las empresas que quebraron no están — el pasado se ve mejor de lo que fue.

B.3 FRED: datos macroeconómicos, gratis

FRED (Federal Reserve Economic Data, de la Fed de St. Louis) es la referencia mundial de series macro: inflación, tasas, PIB, desempleo, spreads — más de 800.000 series. Es la fuente natural para alimentar los modelos ARIMA y VAR del Capítulo 16.

La vía clásica es pandas-datareader (pip install pandas-datareader), que también documenta el acceso a otras fuentes públicas:

import pandas_datareader.data as web
from datetime import datetime

inicio, fin = datetime(2010, 1, 1), datetime(2024, 12, 31)

# Cada serie tiene un código en fred.stlouisfed.org (buscalo en el sitio)
cpi = web.DataReader("CPIAUCSL", "fred", inicio, fin)      # inflación (índice CPI)
tasa_10y = web.DataReader("DGS10", "fred", inicio, fin)    # Treasury a 10 años
desempleo = web.DataReader("UNRATE", "fred", inicio, fin)  # tasa de desempleo

# Varias series de un tiro, alineadas por fecha (la alineación del Capítulo 6)
macro = web.DataReader(["CPIAUCSL", "DGS10", "UNRATE"], "fred", inicio, fin)
print(macro.tail(3))

La alternativa moderna es fredapi, que usa la API oficial con una clave gratuita (se pide en el sitio de FRED en dos minutos):

from fredapi import Fred

fred = Fred(api_key="TU_CLAVE_GRATUITA")
inflacion = fred.get_series("CPIAUCSL")

# Consejo: nunca escribas la clave en el código; guardala en una
# variable de entorno y leela con os.environ["FRED_API_KEY"]

El flujo típico para el Capítulo 16: descargar el CPI, convertirlo a inflación interanual (cpi.pct_change(12)), guardarlo a CSV, y ajustarle un ARIMA — ahora con datos reales.

B.4 Bloomberg: el estándar institucional

En bancos, fondos y mesas de trading, la fuente es la Terminal Bloomberg — datos de calidad auditada, cobertura universal (renta fija, derivados OTC, curvas) y el costo correspondiente (~USD 25.000/año por terminal). Si trabajás en una institución, tu acceso a datos será este.

Cómo funciona el acceso desde Python:

  • La Desktop API (blpapi, la librería oficial de Bloomberg) permite pedir datos desde Python solo si la Terminal está corriendo y logueada en la misma máquina — la licencia es por usuario, y la API respeta eso. No hay versión gratuita ni “clave de prueba”.
  • Sobre blpapi (que es verbosa) la comunidad construyó wrappers pythónicos: xbbg es el más usado hoy. Sus funciones replican las que ya conocés de Excel: bdh (histórico), bdp (dato puntual), bds (bulk).
# Requiere: Terminal Bloomberg abierta + pip install blpapi xbbg
from xbbg import blp

# BDH: serie histórica (equivalente al =BDH() de Excel)
precios = blp.bdh(
    tickers=["AAPL US Equity", "GD30 Corp"],
    flds=["PX_LAST"],
    start_date="2023-01-01",
    end_date="2024-01-01",
)

# BDP: datos puntuales (equivalente a =BDP())
info = blp.bdp("GD30 Corp", flds=["YLD_YTM_MID", "DUR_ADJ_MID"])  # TIR y duración

# BDS: datos "bulk" (p.ej., el cronograma de flujos de un bono)
flujos = blp.bds("GD30 Corp", flds="DES_CASH_FLOW")

Notá la sintaxis de tickers de Bloomberg: "AAPL US Equity", "GD30 Corp" — el sufijo indica la clase de activo (yellow key). Y un detalle contractual que importa: la licencia restringe la redistribución de los datos; podés analizarlos, no republicarlos.
